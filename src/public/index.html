OBS Source Naming Standard

To link any OBS source to a Google Sheet row, append |sheet <row #> to the source name:

Team 1 Name |sheet 2 → Controlled by Row 2
Player Photo |sheet 5 → Controlled by Row 5
Camera Switcher |sheet 9 → Controlled by Row 9 (SourceSwitcher)

Supported Source Types (Column C)

  • Text: Updates GDI+ / FreeType2 text content, color, font flags.
  • Color: Updates color source with hex code (e.g. #3B82F6).
  • Image: Updates image source file path or URL with transition delay.
  • Video: Updates media source local file path with transition delay.
  • Browser: Updates browser source URL.
  • HS: Visibility only (put hide or show).
  • SourceSwitcher (or Switcher): Updates OBS Source Switcher source playlist using ;; separated sources/scenes.

🔄 Source Switcher & Multi-Source Playlists (;; Separator)

How to manage multi-camera rotations, dynamic sponsor reels, and scene switchers from Google Sheets.

When controlling an OBS **Source Switcher** source (such as from exeldro/obs-source-switcher or automated playlist sources), separate each source or scene name with a double semicolon (;;).

📹 Multi-Camera Rotation Caster Desk, Cam A;; Gameplay Direct;; Crowd Wide Angle Splits into 3 separate camera sources in the switcher playlist.
🏷️ Dynamic Sponsor Reel Title Sponsor Banner;; Energy Drink Logo;; Hardware Partner Rotates all active sponsors defined in your broadcast spreadsheet.
⚡ With Visibility Tag Modifier ?show;Main Stage Cam;; Replay Feed;; Crowd Cam Enables the switcher in OBS and populates all 3 sources simultaneously.
💡 Why use ;; (Double Semicolon)?
  • Comma-Safe: Allows source names that already contain commas (e.g. Camera 1, Wide Angle) without breaking.
  • Tag-Safe: Fully compatible alongside single-semicolon formatting tags like ?show; or ?hide;.
  • Instant Real-Time Sync: The tool automatically formats the source list into OBS-native item structures and updates OBS without freezing.

Cell Modifiers & Tags (Column D)

Tag Modifier Syntax Example Effect in OBS
?color=HEX; ?color=FF5500;Grand Finals Sets text to Grand Finals in bright orange (Hex #FF5500).
?fontstyle=strikethrough; ?fontstyle=strikethrough;Eliminated Sets font style to strikethrough.
?fontstyle=underline; ?fontstyle=underline;Champion Sets font style to underline.
?hide; ?hide;Optional Subtitle Sets source visibility to Hidden (Disabled) with the given text/image/switcher.
?show; ?show;Live Subtitle Sets source visibility to Visible (Enabled) with the given text/image/switcher.
;; (Double Semicolon) Cam A;; Cam B;; Cam C Splits multiple scene/source names into playlist items for SourceSwitcher sources. Comma-safe.
