Read-only works with the Sheet ID + API key from the main app. Editing needs the Apps Script bridge (not published yet). Try it on a copy of the production sheet first.
How to set up the bridge
  1. Make a copy of the production sheet (File › Make a copy) and open its Apps Script editor.
  2. Replace Code.gs with the reviewed version and add WebApp.gs from the apps-script folder.
  3. Run setupControlBridge once and copy the token from the execution log.
  4. Deploy › New deployment › Web app · Execute as Me · Access Anyone.
  5. Paste the /exec URL and token here, then press Test bridge.
